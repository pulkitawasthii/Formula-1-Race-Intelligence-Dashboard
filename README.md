# Formula 1 Race Intelligence Dashboard Analysis Report

## Overview
This project provides a comprehensive data analysis of 6,464 race records across 17 Formula 1 seasons using Tableau.

## Project Scenarios Covered
1. **Scenario 1: Mr. Arnold - F1 Team Performance Strategist**
   - Benchmarked team championship points trajectories (Red Bull Racing, Mercedes, etc.).
   - Analyzed tyre compound performance (Soft, Medium, Hard, Intermediate).
   - Identified driver nationality distribution across global talent pools.

2. **Scenario 2: Ms. Lisa - Motorsport Broadcast Analyst**
   - Driver Performance Leaderboard showing cumulative points.
   - Circuit-level Grand Prix participation maps.
   - Podium achievement distributions by driver and constructor.

3. **Scenario 3: Mr. Gilchrist - F1 Technical Regulation Analyst**
   - DNF (Did Not Finish) failure breakdown (engine, brake, collision, mechanical).
   - Driver reliability scoring across 17 seasons to measure regulatory impacts.

## Tools Used
- Tableau Desktop / Tableau Public
- Data Preprocessing & Cleaning
- Data Storytelling & Interactive Dashboards
